Прокси — если сайт «работает только через сервер» Если проверка пишет про CORS или «Failed to fetch», браузер запретил запрос. Свой бесплатный прокси на Cloudflare Workers решает это: нажмите кнопку ниже, вставьте код в новый Worker, а его адрес с ?u={url} впишите сюда. Ключ идёт только через ваш прокси. Пусто = без прокси.
Нужна модель с поддержкой инструментов (tool use). Если сайт их не принимает, режим выключится сам.
Оборванный ответ дописывается автоматически. Если сайт ругается на лимит, уменьшите число (например, до 8000).
Только формат Anthropic, минимум 1024. Сайты в формате OpenAI присылают мысли сами, если поддерживают.
